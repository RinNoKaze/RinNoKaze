**Academic team project · Deployment, debugging and testing**

GradConnect is a student recruitment platform. This summary describes my individual contribution to the team project.

## Project overview

The team application combines a React and TypeScript frontend, an Express API and a PostgreSQL database. It supports graduate and mentor profiles, job discovery and bookmarks, mentorship requests and messaging.
